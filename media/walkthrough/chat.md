# The chat

Open the chat with **Ctrl+Alt+D** (**Cmd+Alt+D** on macOS), or from the Dual Agent icon in the secondary side bar.

- **Claude answers** with read-only tools: it reads, searches, and lists files.
- **Codex checks** the answer independently and gives a verdict.
- If Codex finds a material problem, **Claude revises** once, and both versions stay visible.

Attach images, PDFs, ZIP archives, Office files, notebooks, or code with the paperclip, by pasting, or by dropping files. Type `@` to mention a file in the workspace.

While a message runs you can type the next one; it waits in the queue above the composer. **Retry** or **Edit** under a message runs it again, after undoing the messages that came after it.

If one agent reaches its usage limit, the other carries on alone until the limit resets. If both do, the message pauses and continues by itself after the reset.
