# Review and apply

Edits happen in a Git worktree in the extension's private storage. Your workspace is untouched until you choose:

- **Review all** opens every change in VS Code's diff editor.
- **Apply…** checks the patch with `git apply --check`, then applies it. Nothing is staged or committed. **Apply** on one file applies only that file.
- **Discard…** deletes the copy.

In a folder without Git, and in Agent mode, the agents edit the folder itself after a snapshot. **Keep…** keeps the changes, and **Undo all…** puts back every file the agents changed and deletes the ones they created. Installed software cannot be undone.

Each message shows its token usage; the chart button shows totals for the conversation, today, the last 7 days, and all time, and how much of each subscription's limits is used. **Dual Agent: Delete All History** removes conversations, attachments, and run records for the workspace.
