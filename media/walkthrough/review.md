# Review and apply

Edits happen in a Git worktree in the extension's private storage. Your workspace is untouched until you choose:

- **Review all** opens every change in VS Code's diff editor.
- **Apply…** checks the patch with `git apply --check`, then applies it. Nothing is staged or committed.
- **Discard…** deletes the copy.

Each message shows its token usage; the chart button shows totals for the conversation, today, the last 7 days, and all time. **Dual Agent: Delete All History** removes conversations, attachments, and run records for the workspace.
